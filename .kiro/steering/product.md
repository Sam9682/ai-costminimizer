# Product Overview

CostMinimizer is an AI-powered AWS cost optimization tool that analyzes AWS infrastructure spending and provides actionable recommendations for cost reduction.

## Core Capabilities

- Multi-source cost analysis from AWS Cost Explorer, Trusted Advisor, Compute Optimizer, and Cost & Usage Reports (CUR)
- AI-powered recommendations using AWS Bedrock for natural language cost queries
- Automated report generation in Excel and PowerPoint formats
- Web interface and CLI for flexible usage
- Model Context Protocol (MCP) server integration for AI assistant access
- Secure credential management with encryption support

## Key Use Cases

- Identify cost optimization opportunities across AWS accounts and services
- Analyze spending patterns and trends
- Generate detailed cost reports with specific recommendations
- Query cost data using natural language
- Monitor Reserved Instance and Savings Plans utilization
- Detect cost anomalies and budget alerts

## Output Formats

- Excel workbooks with detailed cost breakdowns
- PowerPoint presentations with executive summaries
- CLI output with tabular data
- Web interface with interactive visualizations
- Email reports via AWS SES integration
